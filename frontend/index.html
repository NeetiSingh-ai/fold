How Fold works

  1. WatchYour app calls Gemini through Fold's gateway. Every answer is logged to Firestore.
  2. AnalyseGemini studies real input/output pairs and decides whether the task is rule-like or truly creative.
  3. FoldGemini writes a small Python function. Fold runs it in a sandbox against real answers and repairs it until it agrees.
  4. ProveCalls it never saw are the exam. It goes live only above 98% agreement; unsure cases return to Gemini.
  5. GuardA sample of live answers is re-checked by Gemini. If agreement drops, Fold reverts automatically.

Drop-in API

Change one URL in your app. Fold decides per request whether Gemini is needed.

curl -X POST /v1/run \
  -H "Content-Type: application/json" \
  -d '{"task": "material_normalize", "input": "Hex bolt M12x50 zinc plated"}'

# -> {"route": "compiled", "output": {"category": "FASTENER", "base_uom": "EA"}, "cost_usd": 0.0, ...}
